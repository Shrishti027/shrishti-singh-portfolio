# Shrishti's Backend Studio

Build a Production-Quality Java Backend Developer Portfolio



Create a complete, modern, premium-looking personal portfolio website for Shrishti Singh, a Java Backend Developer with approximately 3.5–4 years of professional experience.



The website should look like the portfolio of an experienced software engineer, NOT like a generic beginner/developer template.



IMPORTANT DEVELOPMENT RULES



- Build the entire frontend in this single generation.

- Do NOT create a backend yet.

- Do NOT create authentication.

- Do NOT add Supabase.

- Do NOT add a database.

- Do NOT add unnecessary APIs.

- All portfolio content should initially come from local TypeScript/JSON data files.

- Keep the architecture clean so a Java Spring Boot backend can be integrated later.

- Use only free/open-source technologies and libraries.

- Make the application easy to run locally with npm.

- Keep dependencies minimal.

- Do not use paid APIs or services.

- Do not create fake testimonials, fake companies, fake achievements, or fake statistics.

- Use the information provided below only.

- Make every section fully responsive.

- Prioritize excellent desktop AND mobile UI.

- Do not overuse animations.
